# O Voto do Flávio

Os votos do senador Flávio Bolsonaro contra você e o Brasil.

Projeto voluntário. Site estático publicado pelo GitHub Pages.

## Arquivos

- `index.html` contém o site inteiro, com os dados das fichas embutidos.
- `votacoes_flavio_bolsonaro_senado_2023_2026.xlsx` traz as 426 votações nominais de plenário de 2023 a 2026, com matérias, orientações e sinais.

## Fonte

Senado Federal, Portal de Dados Abertos (legis.senado.leg.br/dadosabertos). O conteúdo de emendas e artigos destacados vem da Agência Senado e da imprensa, com o link indicado em cada ficha.
